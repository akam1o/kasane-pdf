# kasane-pdf v0.6.0

## Overview

0.6.0 is the first release of **`redact`**, positional redaction: it
removes what is drawn inside page rectangles — text codes, image
samples, paths, links and, on request, markup annotations — never
paints over anything, and checks the written bytes before returning
them. Whatever it cannot process exactly is a typed error and no PDF.
The release also carries the rendering-fidelity work since 0.5.1.

No public item is removed or changed (`cargo semver-checks` against
0.5.2: no semver update required). MSRV stays 1.92.

## Redaction

```rust
use kasane_pdf::{redact, Document, RedactOptions};

let doc = Document::from_bytes(&bytes)?;
let r = redact(&doc, &[(0, vec![(72.0, 600.0, 300.0, 640.0)])], &RedactOptions::new())?;
std::fs::write("out.pdf", &r.output)?;
for e in &r.elsewhere { /* removed content still found elsewhere */ }
```

CLI: `kasane-pdf redact in.pdf --page 1 --rect 72 600 300 640 --output out.pdf`.

### What a success states

Three separate statements; none implies the next
(`docs/features/redaction.md`):

1. **The rects — verified.** The same rects, run again on the output,
   find nothing left to remove or cut.
2. **The edited originals — verified.** No live stream of the output,
   stored or decoded, equals an edited image's or form's original or a
   removed annotation's appearance, and no dictionary equals a removed
   link or annotation — except an object the output still invokes
   elsewhere, which is reported. The test is equal digests: the same
   picture re-encoded differently is not detected. One revision, no
   unreachable objects.
3. **The rest of the document — reported, not guaranteed.**
   `elsewhere` lists removed text found again and originals still
   invoked; `residual` audits attachments, annotations, form values,
   actions and the rest. `refuse_copies_elsewhere(true)` turns any
   finding into a refusal.

### Scope

Edited: embedded-font text in fill mode (whole glyphs whose ink meets
a rect); 8-bit DeviceGray/RGB images, per page when shared; Form
XObjects nested up to 16 deep, in per-use copies; paths inside a rect
(removed) or crossing it (axis-aligned filled rectangles cut exactly,
straight strokes cut with width, caps, joins, dash phase and CTM);
links meeting a rect; with `remove_annotations`, markup annotations
meeting a rect, removed whole with their popups and replies. Kept as
written: everything clear of the rects, including inline images,
annotations and optional content (which redaction takes as drawn,
hidden or not). `/Info` and XMP are always removed.

### Known limitations

Refused, not approximated (full list in
`docs/features/redaction.md`, *Not covered*):

- **Non-embedded fonts.** A reader draws them with a font of its own
  choosing, so where their glyphs reach is unknown; such text is
  refused (except under a rectangular clip meeting no rect). This is
  the most common refusal on real documents. An earlier, unreleased
  option that decided by a cell around each glyph and hid the rest with
  a clip was withdrawn before this release: a glyph drawn partly inside
  a rect could have stayed in the file as data.
- Type 3 and vertical fonts, invisible (OCR) and other non-fill text,
  `/ActualText`.
- Curves and non-rectangular fills crossing a rect; tiling patterns;
  soft masks; shadings that may paint inside a rect; masked, CMYK or
  indexed images.
- Widgets, signatures and media meeting a rect; signed or encrypted
  documents.
- Square and round line caps cut at a rect lose up to half a line
  width of the band next to it.

The redaction is positional: the same information elsewhere in the
document (other pages, annotations, attachments, form values) is
reported, not removed.

## Rendering and text

- A non-embedded Standard 14 font without `/Widths` is laid out with
  the Adobe Core 14 AFM widths (by its name), as readers lay it out;
  a code without a `/Widths` entry takes `/MissingWidth`.
- Glyphs are placed on the device grid as Poppler's Splash places them,
  a page's pixel size is rounded up, minified images are area-averaged,
  automatic stroke adjustment for `/SA true`, `/BrotliDecode`, link
  borders without appearance streams (see CHANGELOG).

## Verification

- 1,470+ tests; `scripts/verify-redact.py` (qpdf, pdftotext, pdftoppm)
  on every pull request; `scripts/eval-redact-corpus.py` on a slice of
  the corpus (55 files, 117 rect runs): every success had no extracted
  word and no unchanged ink left inside its rect, and lost no word
  outside it; no unexpected failure.
- Independent reviews of every redaction change; all P0/P1 findings
  fixed before release.
