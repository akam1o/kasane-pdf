# kasane-pdf v0.13.1

## Overview

0.13.1 is a security fix for `redact`, cut from v0.13.0. It contains no
other change.

- **Redaction**: a page whose content, forms or the appearances of the
  annotations it keeps draw an inline image (`BI … ID … EI`), or that shows a Type 3 glyph
  drawing one, is refused (`Error::Unsupported`), wherever the image
  lies; such an image away from the rects was kept. Readers do not all
  end inline image data where kasane does.

MSRV stays 1.92. No public signature changes (`cargo semver-checks`
against 0.13.0); the only behaviour change is the refusal above
([`api-stability.md`](../api-stability.md)).

## Security

This version fixes a security issue in redaction. An advisory with the
details will be published once 0.13.1 is available on crates.io;
upgrading is recommended for every application that uses `redact`.

## Compatibility

Pages with inline images that 0.13.0 redacted are now refused. Rendering,
text extraction, rewriting and the content editors are unchanged.
