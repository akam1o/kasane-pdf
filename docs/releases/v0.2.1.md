# kasane-pdf v0.2.1

## Overview

A compatible release of the independent PDF engine: no public item was
removed or changed in signature (`cargo semver-checks` against 0.2.0
reports no semver update required). It renders more conforming and
near-conforming files, separates *strict*, *recovered* and
*approximate* results everywhere they are reported, and fixes two
resource-bound gaps in JPEG decoding.

Several inputs that 0.2.0 **refused** now **succeed**. That is not an
API change, but it is a change callers can observe; the list is under
*Behaviour changes* below.

## Highlights

- **§7.3.10 undefined references.** A reference to an object the file
  does not define is the null object, as the standard requires, in
  strict mode too — recorded once as `Warning::UndefinedReference`.
  Writers and the audit still see `Error::MissingReference`, so a
  rewrite never turns a dangling reference into `null` silently.
- **Open content-stream blocks** (`q`, `BT`, `BMC`/`BDC`, `BX` still
  open at the end of a stream) are closed there and recorded as
  `Warning::UnterminatedContentBlock`.
- **Recovery rules, recorded.** `Document::from_bytes_recovering` now
  also applies the reinterpretations every major reader makes and
  ISO 32000 does not sanction — default page boxes, a stray `Q`, an
  unknown operator, an operator inside a path object, invalid
  annotation entries, undefined `/Properties`, a missing font resource,
  a malformed `/Differences` element, an image `/SMask` that is not a
  stream — each recorded as `Warning::RecoveryApplied { rule:
  RecoveryRule, .. }`. Strict mode refuses every one of them as before.
  `Document::recovery_mode()` reports the mode.
- **Knockout transparency groups** (§11.4.8) are rendered, with
  opacity kept out of each object's shape at any nesting depth and
  `AIS` honoured. New bound `Limits::max_knockout_objects`.
- **Symbol and ZapfDingbats** without an embedded program draw with a
  bundled 414-glyph DejaVu Sans subset (Bitstream Vera licence) through
  their built-in encodings and Adobe AFM widths, reported as
  `SubstKind::SymbolFallback`.
- **Oversized images drawn small.** A JPEG stored larger than
  `max_image_dimension` is decoded with a reduced inverse DCT when it
  is drawn smaller, reported on the new
  `RenderedPage::image_approximations()`. A soft mask finer than its
  image is composited at the mask's resolution (capped at the drawn
  size). The limits themselves are unchanged.

## Fixes

- JPEG frames are checked against the image dictionary, and the
  coefficient memory of progressive frames against `max_image_bytes`,
  *before* decoding. 0.2.0 could allocate beyond `max_image_bytes`
  for a progressive frame or a frame header larger than the dictionary.
- Knockout groups: opacity set inside a nested form no longer reduces
  the object's shape.

## Behaviour changes (refused in 0.2.0, accepted now)

| input | 0.2.0 | 0.2.1 |
|---|---|---|
| reference to an undefined object | `MissingReference` | null + `Warning::UndefinedReference` |
| stream ending inside `q` / `BT` / `BMC` / `BX` | `Structure` | closed + `Warning::UnterminatedContentBlock` |
| rendering intent outside §8.6.5.8 | `Structure` | RelativeColorimetric + warning |
| ASCII85 final group of one character | `Parse` | ignored + `Warning::IgnoredFilterFragment` |
| `/TR /Identity` | `Unsupported` | accepted (identity) |
| knockout group | `Unsupported` | rendered |
| non-embedded Symbol / ZapfDingbats | `Unsupported` | rendered, `SymbolFallback` reported |
| oversized JPEG drawn small; oversized plain soft mask | `LimitExceeded` | rendered; JPEG reported in `image_approximations()` |
| malformed inputs under `from_bytes_recovering` | refused | accepted with `RecoveryApplied` warnings |

A signed document's rewrite and every strict refusal not listed here
are unchanged.

## Compatibility

Measured on the 511-file corpus (427 files expected to be
well-formed, every page): strict render 368 → **378** (88.5 %), of
which 69 used a reported approximation; recovered render 8 → 18,
counted apart from strict; text 384 → 390; full PASS 318 → 325; round
trip 411 unchanged; Poppler SSIM dropped on no file; 43 adversarial
files refused in strict mode without crash or timeout.

## Upgrading

```toml
[dependencies]
kasane-pdf = "0.2"
```

No source change is required. Match `Warning`, `RecoveryRule` and
`SubstKind` with a wildcard arm (all `#[non_exhaustive]`). To keep
0.2.0's refusal of undefined references, check
`doc.take_warnings()` for `Warning::UndefinedReference`.

## Known limitations

- Encrypted documents are still refused (`Error::Encrypted`); support
  is planned for 0.3.0.
- Identity-ordering CID fonts without an embedded program, multi-state
  appearances without `/AS`, transfer functions other than identity,
  `/BrotliDecode` and form nesting beyond `max_xobject_depth` are
  refused.
- Knockout shape is the rasterised coverage of one painting operator;
  a nested non-knockout group counts as one object.
