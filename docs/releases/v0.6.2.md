# kasane-pdf v0.6.2

## Overview

0.6.2 is a security fix release for `redact`. It contains one fix and
its tests; nothing else changes. No public API changes. MSRV stays
1.92. Upgrading is recommended for every application that uses
`redact`.

## Security

### The positioning of removed text was kept (GHSA-9mw8-m2cr-vxqm)

- *What:* when `redact` removed text, the positioning and advances of
  the removed glyphs stayed in the content stream.
- *Fixed:* between two shows that still draw glyphs, the text
  positioning is folded into one exact move to the next kept glyph;
  values set only for removed text and never read by kept content are
  dropped, and empty text objects and saved states left by removed text
  are removed. Kept text stays where it was.
- *What remains, by design:* where the next kept glyph starts (so the
  total width of a removed run on its line, as visible in any
  rendering), the number of `T*` line moves when the leading is
  inherited, marked-content sequences (their `/MCID`) and the page's
  resource dictionaries.

## Behaviour changes

- New refusal: a form, an image or an unknown operator drawn inside a
  text object among removed text, and a `T*` with an inherited leading
  where it cannot be kept in place.
- The content of an edited stream is rewritten more: kept text is
  drawn by fewer operators. Kept glyph positions are unchanged (to
  floating-point rounding: a reader snapping glyphs to its pixel grid
  may shade a line start differently).
