# Plan — v0.5.0: verified rewrites, measured robustness

Status: analysis and plan (2026-11-01), on v0.4.0 (`3b88768`), Linux
nightly 41277691417 (Poppler 26.01 with `poppler-data`) and a macOS
run of the same code. Per-file evidence lives in the gitignored
`compat/reports/v050/`; this file carries only aggregates, anonymised
causes and the plan.

## Method

| phase | how |
|---|---|
| Full PASS gap | every `expect: pass` document that is not a Full PASS (87 of 425) — each stage's first error, normalised, merged into one blocker set per document; every blocker classified (unsupported feature, bug, intentional limit / policy, malformed original, witness defect, gate false positive, environment, undetermined) |
| recoverability | a spike branch (not merged) with environment-gated bypasses of each rewrite refusal (the usage-rights bypass *removes* `/Perms`, i.e. option D1 (b)); the compat runner on the 87 documents with no bypass, each bypass alone and all together: which documents then reach a Full PASS and whether their round trip and semantic round trip pass |
| rendering | the runner's per-file approximations, quality classes and technology inventory (font kinds, image filters, shading, scripts); page-1 render time and peak RSS of the CLI on all 511 files |
| text | every `expect: pass` document with text whose page-1 multiset F1 is below 0.9 (37), split by where the missing characters are (page content, annotations, unresolved codes) |
| limits | the documents refused for a resource limit re-rendered with raised limits |

### What lifting each rewrite refusal would gain (measured, spike)

| bypass | Full PASS gained | round trip | semantic round trip |
|---|---:|---|---|
| usage-rights signature alone (`/Perms` removed) | 0 | — | — |
| XFA, catalog `/AA`, `/Names` JavaScript alone (first spike, without `/OpenAction`) | 4 | identical | 3 unverifiable (XFA) |
| PDF 2.0 alone | 2 | identical | pass |
| dangling reference written as `null` alone | 4 | identical | pass / n.a. |
| usage rights + XFA + `/AA` + JavaScript incl. `/OpenAction` | 32 | identical except the `/Perms` removal | 29 unverifiable (XFA) |
| all together | 39 | identical except the `/Perms` removal | 29 unverifiable (XFA) |

With `/Perms` removed, all 27 rewritten usage-rights forms carry no
`/Perms` and no reachable `/ByteRange` and pass `qpdf --check`; the
runner's structure comparison flags the removal (`/Root/Perms`
dropped), so W4 must make it a *declared* removal the runner accepts.
One document refused for catalog `/AA` also carries an `/OpenAction`
script — a second refusal hidden behind the first. Gains do not add up
per refusal: they come from the merged blocker sets.

The usage-rights documents are government forms that also carry XFA (26
of 27) or a `/Names /JavaScript` tree (1): neither refusal can be lifted alone. The
semantic round trip snapshots only the AcroForm half of an XFA form, so
those rewrites would be *unverified*; extending the snapshot comes first.

### Other dimensions

- **Approximate renders (69)**: 67 are non-embedded Standard 14 fonts
  drawn with the metric-compatible substitutes (reported by design), 1
  an oversized JPEG decoded at reduced size, 1 a Lab-PCS ICC profile.
  None is a defect.
- **Technology inventory** (documents, exact renders): JBIG2 46 / 45,
  CFF CID 40 / 37, CCITT 3 / 2, JPX 3 / 2, Type 3 46 / 32 (the rest are
  approximations or other blockers), shading 32 / 20. The v0.4.0 list
  of rendering gaps (CFF CID, JBIG2, tiling patterns, CCITT, JPX) is
  closed except for single malformed files.
- **Text** (page-1 F1 < 0.9 on 37 of the 250 documents with text on
  either side; 34 of the 37 have Poppler text): 14 have
  their text only in annotations or form fields — `pdftotext` includes
  appearance text, our default does not (the 0.4.0 option does; the
  runner does not use it); 10 have only unresolvable codes (meaningless
  glyph names, Identity-ordering CFF without `ToUnicode`, Type 3 names
  such as `g1`), which Poppler fills by guessing and we decline to; the
  rest are small pages and form-heavy documents. No text defect.
- **Performance** (CLI, page 1, all 511): median < 0.01 s, max 0.74 s;
  RSS median 6 MB, 95th percentile 25 MB. One outlier: a 60 KB page
  whose 1-bit soft mask is 151 megapixels reaches 1.3 GB RSS (the mask
  is expanded at full resolution and again for each of 40 uses) — a
  memory amplification of about 70× the decoded input.
- **Limits**: one real document needs form nesting between 33 and 48
  (`max_xobject_depth` defaults to 32); it renders at 48.

## 4. Decisions needed before implementation

- **D1 — usage-rights signatures in `rewrite`.** A usage-rights
  signature (`/Perms /UR3`) grants Reader features; it is not a
  certification or approval of the content. A full rewrite cannot keep
  it valid. Options: (a) keep refusing (today); (b) rewrite and *remove*
  `/Perms /UR` / `/UR3`, reported as a warning — the output is an
  ordinary, unsigned form, its content unchanged; (c) rewrite and keep
  the invalid signature (rejected: the output would claim rights it no
  longer has). Certification (`/DocMDP`) and approval signatures stay
  refused in every option. Recommendation: (b), with the removal
  recorded in the result and the API docs.
- **D2 — executable content in `rewrite`.** Catalog `/AA`, `/OpenAction`
  JavaScript and `/Names /JavaScript` are refused so that a rewrite
  never "silently retains" a script — but page, annotation and field
  `/AA` and link JavaScript actions are carried today, so the policy is
  not uniform; whatever is decided must apply at every level. kasane-pdf is not a sanitiser
  (README); carrying them verbatim preserves the input. Options: keep
  refusing (today), or carry with a warning. Recommendation: keep
  refusing the catalog level in 0.5.0 (3 documents) unless a user needs
  it; report scripts found at any level in the rewrite result, so none
  is retained silently; revisit carrying with an explicit option.

**Proposed target: ≥ 365 / 425 with D1 = (b) (expected 374), otherwise
≥ 348 / 425** — plus the robustness items (R1, R3, R4) that do not move
the count but keep it honest. Every new rewrite path must pass the
graph, render and *semantic* round trip; a gain without a semantic pass
is not counted.

In scope: V1, V2, W1–W4, R1–R4, C1 (operand-count rule at least).
Out of scope (P2, later): F1–F4, G1–G3, E1, A1, W5 unless D2 changes.

## 6. Phases

Each phase merges alone, with the full gates, a Linux nightly and a
baseline update explained file by file.

| phase | content | prerequisites | acceptance | corpus effect | effort (d) | risk |
|---|---|---|---|---|---:|---|
| A. verification first | V1, V2 | — | snapshot categories with synthetic tests (each category: equal, changed, missing); runner tests; nightly shows the new categories on current rewrites with 0 failures | semantic categories +5; text metric with annotations (report only) | 4 | low |
| B. spec-exact rewrites | W1, W2, W3 | A | each with failing-first tests; every gained document passes graph, render and semantic round trip; qpdf / Poppler report nothing new | Full PASS 338 → ≈ 347 | 5 | low–medium |
| C. usage rights (after D1) | W4 | B, D1 | DocMDP / approval still refused (tests); `/UR` and `/UR3` removal declared, reported and accepted by the runner's structure comparison; no `/Perms` and no reachable `/ByteRange` in the output; Reader-extended synthetic forms rewrite to valid unsigned forms (qpdf, Poppler) | ≈ +26 → ≈ 373 | 2 | medium |
| D. robustness | R1, R2, R3, R4 | — (parallel to A–C) | R1: the outlier below 100 MB, no pixel change; R2: stack per nesting level measured on native and wasm32, new default documented; R3: audit list closed, 32-bit CI job green; R4: new targets in CI build, 1 h local run without findings | +1 (R2) | 9 | medium |
| E. recovery rules (droppable) | C1 | — | each rule a `RecoveryRule` variant (additive), synthetic tests, strict behaviour unchanged | recovered renders +≈10 | 4 | medium |
| F. release | gates, docs, notes | A–E | the 0.4.0 release procedure | — | 2 | low |

Total ≈ 26 days (A–F), ≈ 30 with a 15 % contingency; phase E is the
first to drop if the schedule slips. The order A → B →
C is fixed (no unverified rewrite path); D and E are independent.

## 7. Quality gates

Unchanged and enforced: the release gates (36 steps), PR CI, CodeQL,
nightly, robustness 44 / 44, round trip, semantic round trip, the
exact-render quality gate, crash / timeout 0, `cargo semver-checks`.
New measurements start report-only: the semantic categories of V1, the
text agreement with annotations (V2), page-1 render RSS and time per
file (a budget flagged, not enforced, until a period of nightlies).

## 8. Done means

Synthetic tests that fail before the change; the corpus effect measured
on the Linux nightly and explained file by file; an independent check
(Poppler, qpdf, or the semantic round trip) agreeing; no regression in
any enforced gate; fuzzing of the touched code; the CHANGELOG, the
limitations and this plan updated.
